第一次发布：怎样获取授权？
  1. 打开 GitHub 的细粒度 Token 页面 ↗。
  2. 选择账号 Warren-xh，设置名称和有效期。
  3. Repository access 选择 Only select repositories，只选 travel-atlas。
  4. Repository permissions 中设置 Contents → Read and write，其他权限无需增加。
  5. 生成后复制到上面的输入框。Token 不会写入网站文件、备份或本地存储。

发布仅修改 data/atlas.json。GitHub Pages 需要一点时间更新网页。

数据来源

边界：Natural Earth 1:50m，经 d3-maps atlas 转换。小型国家用圆点补充显示；地图轮廓用于个人旅行记录。

名称与大洲：mledoze/countries。跨洲国家可能出现在两个大洲。

免签预填：中国领事服务网普通护照适用协定，以及目的国外交部、驻外使馆公告。只预填已核实的部分国家，透明不代表需要签证。

免签不等于满足所有入境、中转和返程条件；停留期限以目的国现行规定为准。颜色可由你自行调整。

绘图：D3.js。本网站不使用付费地图接口。
